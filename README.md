# دارو (Daroo)

مخزن آزمایشی: **هوش مصنوعی برای ساخت داستان تا کجا رسیده است؟**

پاسخ، فقط ادعا نیست — یک داستان کوتاه فارسی به‌نام **«دارو»** در همین مخزن ساخته شده است:
متن (پنج صحنه)، پنج تصویر با کاراکترِ یکسان، و پنج قطعه‌ی روایت صوتی فارسی.

📖 **صفحه‌ی نمایش:** `story-lab/index.html`
📄 **گزارش توانمندی و مرزها:** `story-lab/REPORT.md`
✍️ **متن کامل + انجیل داستان + پرامپت‌ها:** `story-lab/story.md`

خلاصه‌ی حکم: مدل‌های زبانی امروز «داستانِ کوتاهِ خوب» را در چند دقیقه می‌سازند و می‌توانند همان را تصویر کنند و بخوانند؛
اما **انسجام در مقیاس رمان** و **قضاوت درباره‌ی خوب و بد** همچنان ضعف اصلی است — و آن‌جاست که ویرایشگرِ انسانی تعیین‌کننده می‌ماند.
