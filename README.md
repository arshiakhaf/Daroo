# دارو (Daroo)

مخزن آزمایشی: **هوش مصنوعی برای ساخت داستان تا کجا رسیده است؟**

---

## ۱) داستانِ کوتاهِ «دارو» — نمایشِ توانایی
پنج صحنه + پنج تصویر با کاراکترِ یکسان + پنج روایت صوتی فارسی.

- 📖 صفحه‌ی نمایش: `story-lab/index.html`
- 📄 گزارش توانمندی و مرزها: `story-lab/REPORT.md`
- ✍️ متن، انجیل داستان و پرامپت‌ها: `story-lab/story.md`

## ۲) رمانِ کوتاهِ آموزشی «آمپولِ نهم» — یادگیری با داستان
یک شیفتِ شب (۲۰:۰۰ تا ۰۷:۱۰) در بیمارستانی که بخشِ قلب و زایشگاهش موقتاً ادغام شده‌اند؛
یک داستانِ جنایی/بالینی که در آن، **کلِ سرفصلِ دو درسِ داروشناسی** جا داده شده است:
فارماکولوژیِ مامایی + داروشناسیِ پرستاریِ بیماری‌های قلب‌وعروق.

هر صحنه با یک بلوکِ «دِبریف» (جدولِ مرور) تمام می‌شود و بخشِ ۱۰، «جزوه‌ی جامع» هر دو درس است.

- 📖 صفحه‌ی نمایش (با فهرست): `story-lab/pharma/index.html`
- ✍️ متنِ کامل: `story-lab/pharma/story-full.md` · بخش‌ها: `story-lab/pharma/story/part1..10.md`
- 🖼 تصاویر: `story-lab/pharma/assets/`

> **یادداشتِ صادقانه:** دو فایلِ PDF جزوه‌ها به محیطِ ساخت نرسید؛ متن با استانداردِ سرفصلِ همین دو درس نوشته شده است.
> برای هم‌ترازکردنِ واژه‌به‌واژه با نسخه‌ی کلاس، فایل‌ها را دوباره بفرستید.
