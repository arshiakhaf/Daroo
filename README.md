# دارو (Daroo)

مخزن آزمایشی: **هوش مصنوعی برای ساخت داستان تا کجا رسیده است؟**

---

## ۱) داستانِ کوتاهِ «دارو» — نمایشِ توانایی
پنج صحنه + پنج تصویر با کاراکترِ یکسان + پنج روایت صوتی فارسی.

- 📖 صفحه‌ی نمایش: `story-lab/index.html`
- 📄 گزارش توانمندی و مرزها: `story-lab/REPORT.md`
- ✍️ متن، انجیل داستان و پرامپت‌ها: `story-lab/story.md`

## ۲) رمانِ کوتاهِ آموزشی «آمپولِ نهم» — یادگیری با داستان
یک شیفتِ شب (۲۰:۰۰ تا ۰۷:۱۰) در بیمارستانی که بخشِ قلب و زایشگاهش موقتاً ادغام شده‌اند؛
یک داستانِ جنایی/بالینی که در آن، **کلِ سرفصلِ دو درسِ داروشناسی** جا داده شده است:
فارماکولوژیِ مامایی + داروشناسیِ پرستاریِ بیماری‌های قلب‌وعروق.

هر صحنه با یک بلوکِ «دِبریف» (جدولِ مرور) تمام می‌شود. ساختار: صحنه‌های ۱–۹ شیفتِ شب (۲۰:۰۰ تا ۰۷:۱۰)، صحنه‌ی ۱۰ مبانیِ فارماکولوژی و فارماکوکینتیک، ۱۱ سامانهٔ عصبیِ خودکار، ۱۲ آسم و آنتی‌هیستامین، ۱۳ تشنج/خواب/اوپیوئید/ضدِصرع، ۱۴ دوپامین و پارکینسون، ۱۵ بحرانِ فشار و سیانید، و **بخش ۱۶** «آخرین برگِ دفتر»: جدولِ جامعِ هر دو درس + نقشه‌ی خواندن + آنتیدوت‌ها.

- 📖 صفحه‌ی نمایش (با فهرست): `story-lab/pharma/index.html`
- ✍️ متنِ کامل: `story-lab/pharma/story-full.md` · بخش‌ها: `story-lab/pharma/story/part1..16.md`
- 🗺 نقشه‌ی پوششِ موضوعی (فصل‌به‌فصلِ جزوه‌ها): `story-lab/pharma/COVERAGE.md`
- 📚 متنِ استخراج‌شده‌ی خودِ جزوه‌ها: `story-lab/pharma/source/` (با `extract.py`)
- 🖼 تصاویر: `story-lab/pharma/assets/`

> **منبع:** دو PDFِ جزوه (فارماکولوژیِ مامایی ۱۴۰۴ و داروشناسیِ پرستاریِ قلب‌وعروق) در مخزن قرار دارند؛
> متنشان با `pharma/extract.py` استخراج شده و داستان فصل‌به‌فصل با همان متن هم‌راستا شده است.
> جدولِ تطبیقِ صفحه‌به‌صحنه در `pharma/COVERAGE.md` است؛ اگر موضوعی جا افتاده، بگویید تا اضافه شود.
